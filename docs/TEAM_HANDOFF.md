# ATLAS team handoff

Start with [the audit](BASELINE_AUDIT.md), [task board](TASK_BOARD.md) and [testing](TESTING.md). Use the isolated feature branch and protect the original Windows checkout.

Run `node packages/cli/dist/bin.js --help` after the build. `lookup`, `search`, `decode`, `event`, `logs`, `tx` and `4byte` cover the established core. `artifact`, `ens-role` / `publisher` and `explain` require the corresponding API adapter and service setup.

Use [deployment](DEPLOYMENT.md) and [sponsor readiness](SPONSOR_READINESS.md) to stage the public release. Record the proven workflow in [the demo script](DEMO_SCRIPT.md). Confirm [eligibility](HACKATHON_ELIGIBILITY.md) before applying for prizes.
