# ETHGlobal Mumbai eligibility

The [event's submission details](https://ethglobal.com/events/mumbai/info/details) list November 7, 2026 at 09:00 IST, up to three partner groups and an optional 2–4 minute demo video. The team should confirm the live Hacker Dashboard cutoff and registration track.

Classic requires project-specific work to start during the event. Continuity permits eligible existing projects with clear disclosure of the prior work and event changes. Document the actual cutoff commits, existing Studio/design assets, meaningful human contributions and AI-assisted code before submitting. Use the team's account to submit.

Check the [official prize requirements](https://ethglobal.com/events/mumbai/prizes) for each track. Arkiv and its Swarm bonus count under one partner group. ENSv2 accepts Ethereum Mainnet or Sepolia with a functional live demo and meaningful ENSv2 functionality. Anon-RPC requires RPC reads through Anon-RPC by default for app entries. 0G asks for inference in the main flow with actual provider request IDs. Select only qualifying features demonstrated with real evidence.
